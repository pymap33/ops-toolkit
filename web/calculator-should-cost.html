4. Overhead, margin and uncertainty

When NOT to use this

  • It is a rough estimate. Use it as a reference range for a negotiation, not as proof that a quote is wrong. The range is an outer bound with every input at one extreme, not a confidence interval.
  • All prices and rates are yours; the tool has no market data. Garbage in, garbage out.
  • One web width for the whole chain, so a slit-down or an extrusion step at a different width is approximated. Web-based products only; not rigid packaging, thermoforming, molding or corrugate.
  • Waste is step run yield plus fixed setup waste, valued at the cost carried into that step. No scrap resale or regrind credit.
  • Overhead and margin are percentages. Plant allocation, freight, minimum-order charges, payment terms and tariffs are not modeled. Overhead at a downstream stage applies to what it receives as well as what it adds, so it compounds.
  • Validation is structural and arithmetic only: the published examples are vendor web pages, one with an error (see the validation notes in the repository).
